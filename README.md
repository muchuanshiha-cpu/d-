# 一键找实习

一个在 Windows 上运行的 Python 单文件工具：读取同目录的 `简历.docx`，根据教育经历、技能和求职方向检索公开招聘信息，整理匹配结果并生成 `适合你的岗位.docx`。

## 使用前

- Windows 电脑，建议使用较新的 Python 3。
- 将脚本和自己的简历 Word 文件放在同一文件夹，简历文件名为 `简历.docx`。
- 按脚本提示输入搜索中心；不要把身份证号、家庭住址等无关敏感信息写入简历。
- 运行后查看生成的 Word 文档，并自行核实岗位是否仍在招聘、企业信息和投递要求。

## 运行

安装 Python 后，在命令提示符运行：

```powershell
py -m pip install requests beautifulsoup4 python-docx
py "一键找实习_公开分享版.py"
```

也可以在已配置 Python 的 Windows 环境中双击脚本运行。若缺少模块，按报错提示安装依赖。

## 说明与限制

- 本工具检索公开网页，不代表覆盖所有招聘平台或全部岗位。
- 搜索结果可能过期、重复、信息不完整，或受到网站访问限制；请以招聘单位发布的最新信息为准。
- 岗位匹配和距离仅供筛选参考，不构成录用、薪资或通勤保证。
- 脚本不会替你投递简历；请在核实招聘主体、岗位要求和官方投递渠道后自行决定。
- 请遵守相关网站使用规则及适用法律法规，不要用于高频请求、绕过访问控制或收集无关个人信息。

## 隐私

简历可能包含个人信息。请仅在可信设备上运行，避免将简历、生成的岗位报告、访问密钥或其他个人数据上传到公开仓库或发送给陌生人。本仓库只用于分享脚本和说明，不收集你的简历。
